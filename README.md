Do you want to change you desktop background with one click?
Something like Microsoft Bing but here you get to choose from your own pictures.

Here is how.

1. Unzip the file.
2. Create a folder in your disk D: and name it "wallpapers"
3. Copy the wallpapers.ps1 file inside this folder. (In order to work it is crucial to be exactly in disk D: with folder name "wallpapers" unless you know how to change the .ps1 script).
4. Place the "change wallpaper" short cut file on your desktop.
   
Done

Now place pictures inside the wallpapers folder that your want to be set as a background. When click on the short cut the script will automatically change your desktop wallpaper with randomly selected picture from the folder.

For sys anmins!
Change the script and short cut paths with you local file server directory where you want to place the folder and copy the short cut to the users desktops.
